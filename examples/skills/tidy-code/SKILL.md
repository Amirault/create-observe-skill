# Tidy Code

A made-up skill: its runs are generated by `examples/generate_transcripts.py`, never by a real agent.

## Step 1 — Pick the files

Launch a triage subagent: it reads `references/picking-rules.md` and picks the N files.

## Step 2 — Clean

Run `lintkit --fix <file>` on each file, then `pytest -q`. Red tests → report ABORTED and stop.

## Step 3 — Review and PR

Commit, launch a cold review subagent on the diff, then `gh pr create --fill`.

End with a `## Tidy report` heading and an `**Outcome**:` line (PR OPENED or ABORTED).
